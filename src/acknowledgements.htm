This ePub version of the ཆོས་སྤྱོད། (chos spyod) has its origins from a version found randomly on the Internet. That first version was a very crude ePub-file, auto-generated from what might have been an MS Word file. It had multiple inserted advertisments from the free version of an ePub generator tool. I found it to be a useful starting point for making a cleaner and more easily navigable version, without having too seek out the actual source files that might have been used to create it, and what is the original file for the printed version of the text.

This current version remains an edited version of that original Internet-find. Seeking out a more official source file by liasioning with the producer of the printer version would seem to be the next natural step in making and keeping this eBook up to date, but so far my attempts at that have been feeble and unsuccessful. This work still remains a useful tool for practitioners, and is a good basis for showing a proof-of-concept, learning about the EPUB format, and for experimenting with useful design and nagivation support.

Since the work on this e-book started, the printed version has been updated once or twice, and a few prayers/practices have been added that are not included here, most notably The Ultimate Guru Sadhana of Simplicity and Calling the Guru From Afar.
